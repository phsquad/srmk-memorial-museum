# Сборка и развёртывание проекта

## Требования
- Node.js 18+ 
- npm 9+

## Установка зависимостей
```bash
npm install
```

## Команды сборки

### Режим разработки (dev server)
```bash
npm run dev
```
Запускает локальный сервер на порту 3000 с горячей перезагрузкой.

### Продакшн-сборка
```bash
npm run build
```
Создаёт оптимизированную сборку в папке `dist/`:
- Минификация JS и CSS
- Удаление console.log и debugger
- Хеширование имён файлов для кэширования
- Оптимизация изображений (WebP + fallback)
- Gzip-сжатие

### Предварительный просмотр сборки
```bash
npm run preview
```
Запускает локальный сервер для просмотра продакшн-сборки.

## Структура выходных файлов
```
dist/
├── index.html              # Главная страница
├── guestbook.html          # Книга памяти
├── memory-book.html        # Книга памяти (мобильная)
├── reader.html             # Читалка
├── certificate.html        # Сертификаты
├── desk-qr.html            # QR-код для стенда
├── methodology.html        # Методология
├── mobile.html             # Мобильная версия
├── quiz.html               # Викторина
├── verify.html             # Проверка сертификатов
└── assets/
    ├── css/                # Минифицированные стили
    ├── js/                 # Бандлы JavaScript
    └── images/             # Оптимизированные изображения
```

## Развёртывание

### Статический хостинг
Скопируйте содержимое папки `dist/` на любой статический хостинг:
- GitHub Pages
- Netlify
- Vercel
- Firebase Hosting

### Пример для GitHub Pages
```bash
npm run build
npx gh-pages -d dist
```
