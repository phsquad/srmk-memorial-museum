КАК ПОДКЛЮЧИТЬ ЕДИНУЮ ШАПКУ:
-----------------------------

ВАРИАНТ 1 (PHP сервер):
  <?php include 'includes/header.html'; ?>

ВАРИАНТ 2 (JavaScript fetch):
  <div id="common-header-container"></div>
  <script>
  fetch('includes/header.html')
    .then(r => r.text())
    .then(data => {
      document.getElementById('common-header-container').innerHTML = data;
    });
  </script>

ВАРИАНТ 3 (Ручное копирование):
  Скопируйте содержимое includes/header.html в каждую страницу

ПОДКЛЮЧЕНИЕ СТИЛЕЙ:
--------------------
В <head> каждой страницы добавьте:
  <link rel="stylesheet" href="css/header-common.css">

ПОДКЛЮЧЕНИЕ JS МОДУЛЯ:
-----------------------
Перед </body> каждой страницы добавьте:
  <script src="js/navigation.js"></script>

ФУНКЦИИ NAVIGATION.JS:
-----------------------
- SiteNavigation.init()              - Автоинициализация
- SiteNavigation.navigateTo(page)    - Переход на страницу
- SiteNavigation.getPagePath(name)   - Получить путь к странице
- SiteNavigation.pageExists(name)    - Проверка существования
- SiteNavigation.toggleMobileMenu()  - Управление мобильным меню
