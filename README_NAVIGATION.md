# Инструкция по подключению единой навигации

## Обзор

Этот документ описывает процесс подключения единой навигационной шапки на все страницы сайта виртуального музея ГБПОУ СРМК.

## Созданные файлы

1. **`includes/header.html`** — HTML-шаблон единой шапки
2. **`css/header-common.css`** — CSS-стили для навигации
3. **`js/navigation.js`** — JavaScript-модуль для интерактивности

## Способы подключения

### Способ 1: Ручное копирование (для статических HTML-страниц)

#### Шаг 1: Подключить CSS в `<head>` каждой страницы

```html
<head>
  <!-- ... другие стили ... -->
  <link rel="stylesheet" href="css/header-common.css">
</head>
```

#### Шаг 2: Вставить HTML-шаблон после `<body>`

Откройте `includes/header.html`, скопируйте содержимое и вставьте его в начало каждой страницы сразу после открывающего тега `<body>`:

```html
<body class="dark-theme">
  <!-- ВСТАВИТЬ СОДЕРЖИМОЕ includes/header.html ЗДЕСЬ -->
  
  <main>
    <!-- Основной контент страницы -->
  </main>
  
  <!-- Подключить JS перед закрывающим </body> -->
  <script src="js/navigation.js"></script>
</body>
```

#### Шаг 3: Подключить JS перед `</body>`

```html
  <script src="js/navigation.js"></script>
</body>
```

---

### Способ 2: PHP include (если используется PHP)

#### Шаг 1: Переименовать страницы в `.php`

Если ваши страницы имеют расширение `.html`, переименуйте их в `.php`:
- `index.html` → `index.php`
- `guestbook.html` → `guestbook.php`
- и т.д.

#### Шаг 2: Подключить CSS в `<head>`

```php
<head>
  <link rel="stylesheet" href="css/header-common.css">
</head>
```

#### Шаг 3: Использовать PHP include

```php
<body class="dark-theme">
  <?php include 'includes/header.html'; ?>
  
  <main>
    <!-- Контент страницы -->
  </main>
  
  <script src="js/navigation.js"></script>
</body>
```

---

### Способ 3: JS fetch (динамическая загрузка)

#### Шаг 1: Подключить CSS в `<head>`

```html
<head>
  <link rel="stylesheet" href="css/header-common.css">
</head>
```

#### Шаг 2: Добавить контейнер для шапки

```html
<body class="dark-theme">
  <div id="header-container"></div>
  
  <main>
    <!-- Контент страницы -->
  </main>
  
  <script src="js/navigation.js"></script>
  <script>
    // Загрузка шапки через fetch
    fetch('includes/header.html')
      .then(response => response.text())
      .then(html => {
        document.getElementById('header-container').innerHTML = html;
      })
      .catch(error => console.error('Ошибка загрузки шапки:', error));
  </script>
</body>
```

## Функционал навигации

### Элементы шапки

1. **Логотип** — переход на главную страницу
2. **Навигация по залам** — 4 основных раздела экспозиции
3. **Выпадающее меню модулей** — доступ ко всем цифровым сервисам
4. **Кнопка сертификата** — быстрый доступ к генератору
5. **Паспорт проекта** — информация о проекте
6. **Карта Доблести РФ** — ссылка на внешний ресурс
7. **Мобильное меню (бургер)** — для мобильных устройств

### Интерактивность (navigation.js)

- Открытие/закрытие выпадающего меню
- Выдвижная мобильная панель
- Модальное окно паспорта проекта
- Подсветка активной страницы
- Закрытие меню по клику вне области
- Закрытие по клавише Escape

## Адаптивность

CSS включает медиа-запросы для различных разрешений:

- **>1024px** — Полная версия с настольной навигацией
- **≤1024px** — Скрытие настольной навигации, показ бургера
- **≤768px** — Упрощенная версия логотипа

## Проверка работоспособности

После подключения проверьте:

1. ✅ Шапка отображается корректно на всех страницах
2. ✅ Все ссылки работают и ведут на правильные страницы
3. ✅ Выпадающее меню открывается/закрывается
4. ✅ Мобильное меню работает на устройствах ≤1024px
5. ✅ Кнопка паспорта открывает модальное окно
6. ✅ Активная страница подсвечивается в меню
7. ✅ Стили не конфликтуют с существующими стилями страницы

---

## Примечания

- Файл `header-common.css` должен подключаться **после** основных стилей страницы, чтобы иметь приоритет
- Файл `navigation.js` должен подключаться **перед** закрывающим тегом `</body>`
- Для корректной работы шрифтов убедитесь, что Google Fonts подключен на странице
- Пути к файлам указаны относительные — проверьте их корректность для вашей структуры
