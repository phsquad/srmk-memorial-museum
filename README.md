# Цифровой мемориальный комплекс ГБПОУ СРМК «Быть воином — жить вечно»

Интерактивный цифровой мемориальный комплекс памяти 20 выпускников Ставропольского регионального многопрофильного колледжа, совершивших бессмертный подвиг при защите Отечества. Проект разработан для Всероссийской акции «Карта доблести: хранители подвигов» в номинации «За партой героя».

Проект полностью оптимизирован для хостинга статических сайтов **GitHub Pages**, оснащен глубокой двухсторонней интеграцией с облачной СУБД **Supabase (Realtime Omni-Sync)** и функционирует в автономном режиме (**Offline-First / LocalStorage Fallback**) без сбоев.

## ⚡ Интеграция с базой данных Supabase

Комплекс тесно связан с СУБД Supabase и использует 13 таблиц и хранилищ:
- `heroes_database` — архивные досье 20 героев колледжа.
- `memorial_counters` — онлайн-счетчики зажженных свечей и возложенных цветов.
- `guestbook_tributes` & `tribute_flames_votes` — послания Стены Памяти и реестр лампад.
- `quiz_results` — результаты квеста и глобальный лидерборд Зала Славы.
- `certificates_registry` — реестр сертификатов с криптохэшами SHA-256.
- `hall_analytics_counters` & `hall_analytics_events` — анонимная посещаемость залов и dwell time.
- `user_achievements` & `achievement_unlock_events` — звания и 16 бейджей наградной палаты.
- `museum_realtime_metrics` — агрегированный хаб музейной статистики.

### Настройка Supabase за 3 шага:

1. **Создайте проект**:
   Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте новый проект.
2. **Выполните SQL-миграцию**:
   В боковом меню Supabase откройте **SQL Editor** ➔ **New query**, скопируйте файл [supabase_migration.sql](file:///c:/Users/Alexander%20Talents/Downloads/srmk-memorial-museum/supabase_migration.sql) и нажмите **Run**.
3. **Подключите сайт**:
   - Вставьте ваш **Project URL** и **Anon API Key** в файл [js/config.js](file:///c:/Users/Alexander%20Talents/Downloads/srmk-memorial-museum/js/config.js).
   - **ИЛИ** нажмите на индикатор **Supabase** в шапке любого зала (или горячие клавиши `Ctrl + Shift + S`), вставьте реквизиты, нажмите **«Проверить связь»** и **«Заполнить базу (20 героев)»**.

## 🚀 Развертывание на GitHub Pages

Сайт полностью автономен, не требует Node.js в продакшене и оптимизирован для GitHub Pages:

1. Загрузите файлы репозитория на GitHub:
   ```bash
   git init
   git add .
   git commit -m "Мемориальный комплекс ГБПОУ СРМК v2.0"
   git branch -M main
   git remote add origin https://github.com/<ваш-аккаунт>/<имя-репозитория>.git
   git push -u origin main
   ```
2. В репозитории GitHub перейдите в **Settings** ➔ **Pages**.
3. В разделе **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`, папка `/ (root)`
4. Нажмите **Save**. Через 1 минуту мемориал будет доступен по адресу `https://<ваш-аккаунт>.github.io/<имя-репозитория>/`.

> **Примечание:** В корне репозитория создан файл `.nojekyll`, исключающий обработку движком Jekyll, и файл `404.html`, обеспечивающий маршрутизацию.

## 💻 Локальный запуск для разработки

- **С помощью встроенного HTTP-сервера Node.js (без сторонних зависимостей)**:
  ```bash
  npm start
  # или
  node server.js
  ```
- **С помощью встроенного сервера Python**:
  ```bash
  python -m http.server 3000
  ```
Сервер будет доступен по адресу: `http://localhost:3000`.
